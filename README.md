# CatunBond

## Overview

CatunBond is a voice, video and chat app built with high-quality backend and frontend code using Next.js, Prisma and CockroachDB. CatunBond is designed to provide a seamless and user-friendly experience for users to chat, talk and interact with each other. Catunbond is a secure, fast and stable communications platform with a modern and stylized UI. Catunbond focuses highly on user experience and comfortability.

## Roadmap && Features

-  [x] A working chatting system with servers, channels and messages
-  [x] A secure and fast backend using Prisma and CockroachDB
-  [x] Modern UI developed with CSS and React
-  [x] User Authentication using Clerk
-  [ ] Real-time notifications
-  [ ] Stable and fast voice calls
-  [ ] File sharing using Content Delivery Network (CDN)
-  [ ] Customisable and user-defined UI

## Installation

To install and run a local fork of CatunBond;

1. Clone the git repository.
```bash
git clone https://github.com/Deniz-seckin55-new/CatunBond.git
cd CatunBond
```

2. Run the local servers on seperate terminals.
```bash
npm run dev
npm run node
```

That's it! Now you can visit ==localhost:3000/app== to start using CatunBond.
